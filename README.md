# StyleAttractorLab

A small lab for studying **style attractors** in LLM generation: short style references or discourse frames that can pull not just wording, but reaction order, sentence structure, social stance, closure behavior, and other generation habits into a different basin.

This repository starts as a notebook, not a finished framework. Early material lives under `notes/`; schemas, recipes, evals, and tooling can be promoted only after the concepts survive a few rounds of testing.

## Working distinction

- **Persona**: who is speaking.
- **Style attractor**: how the response naturally grows.
- **Recipe**: how multiple attractors and constraints are combined for a task or persona.
- **Eval**: whether the intended behavior survives ordinary prompts, technical prompts, ambiguity, correction, and low-context turns.
